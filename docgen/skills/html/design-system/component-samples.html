レイアウト

骨格は .dg-page の中に、ヘッダー、h1、リード文、目次、.dg-wrap、フッターを並べる。.dg-wrap の中は main と、任意の aside (用語集) の 2 つだけ。用語集は dl に dt と dd を並べる。aside があれば 2 カラム、なければ本文の行長を抑えた 1 カラムになる。切り替えのためのクラスは無い。

ヘッダーは span 2 つ。左に分類やテーマ、右に日付・版・実験番号など、その文書を特定する印を置く。

ダークモードの切り替えボタンはマークアップに書かない。theme.js が body に button.dg-theme-toggle を追加し、ウィンドウの右上に固定表示する。選択は localStorage に保存され、次回から描画前に反映される。

見出しは h2 を節に、h3 を小節に使う。目次の項目は h2 の id に対応させる。

小節の見出し

見出しに乗せると右に # が現れ、その見出しへのリンクになる。id を書かなかった見出しには文面から id が付く。

ブロック

ブロックは 2 種類。読み飛ばしてほしくない内容は .dg-note に入れる。白地に枠で本文から浮き、data-label を書くと枠にまたがるタグが付く。ラベルはそのブロックの見出しで、中身を要約せず何の話かを示す。ラベルの語で種別を示すので、色は変えない。

.dg-note は注意、制限、前提などに使う。

data-label は省ける。種別を名乗るまでもないときはタグなしで書く。

本題から外れる前提や参考情報は .dg-sub に入れる。沈んだ面に乗り、枠を持たないので本文の流れを切らない。目次も同じ見た目になる。

補助情報のブロック。読まなくても本文が成立する内容を置く。

独立した情報のまとまりは .dg-card に入れる。複数を並べるときは .dg-grid で包むと、幅に応じて段数が自動で変わる。

テンプレート

文書の骨格と、CSS・JavaScript の正しい読み込み順を提供する。

本文

段落には リンク、strong (黒の太字)、em (アクセント色)、インラインコード を使える。CSS のような略語は abbr に title を付ける。アクセント色の強調は、節ごとに 1 箇所を目安にする。

並列の固有名やファイル名は chip で並べる: template.html document.css bundle.py

図と対応する系列を区別したい chip にだけ c1〜c5 を順に付ける: 構造 文字 表 図 コード

  • 箇条書きは素の ul と ol を使う
    • 入れ子もそのまま書ける
  • 順番に意味のある手順は次の ol.dg-steps にする
  1. テンプレートとデザインシステムをコピーして、分離した状態で原稿を書く。
  2. screenshot.sh でライトとダークを描画し、画像を目で確認する。
  3. bundle.py で単一ファイルにまとめ、納品物をもう一度描画する。

区切り線は hr で引く。h1 の下線と同じアクセント色で、文書の中では目立つ線になる。節の分かれ目は h2 が示すので hr は要らない。見出しを立てるほどではないが話の向きが変わる、という切れ目にだけ置く。1 つの文書で数本を上限と考え、段落の間隔を空けたいだけのときや、箇条書きと本文の境目には使わない。

コード

コードは pre > code.language-* に書く。Highlight.js が言語クラスを見て色を付ける。色付けしない場合は language-plaintext にする。

<div class="dg-note" data-label="制限">
  <p>バンドラは stdlib だけで動く。外部パッケージは使えない。</p>
</div>

差分は pre.dg-diff に書き、各行を span.add、span.del、span.ctx で包む。行頭の記号は CSS が付けるので書かない。緑と赤はこの部品だけの機能色。

aside table {
  white-space: nowrap;
  table-layout: fixed;
}

色のトークン

色はすべて CSS 変数で、ダークモードでは値だけが切り替わる。ページ固有の <style> や図の中で色を指定するときは、カラーコードを書かずにこの変数を参照する。ここに挙げていない変数 (本文や枠線の色など) は CSS が自動で当てるので、書き手が触ることはない。

表 3. 書き手が指定する色トークン
トークン見本用途
--dg-accent1アクセント 1 (teal)。h1 の下線、リンク、ラベル、番号。図の中で強調する線や枠に
--dg-accent2アクセント 2 (amber)。em と同じ色。図の中で注意を引く要素に
--dg-muted補助の色。図の注記や補足の線に
--dg-c1 〜 --dg-c5 系列色。複数の系列を区別するときだけ順に使う。本文には使わない
--dg-surface部品の面。図の中に面を置くときの背景
--dg-rule細い区切り線。図の中の補助線に

図の中では、これらの変数を直接書く代わりに class="accent1"、class="accent2"、class="muted"、class="c1" のようなクラスでも指定できる。

図

図は figure の直下に SVG、画像、または Mermaid を置き、figcaption で番号と説明を書く。自作図はインライン SVG で、線と文字は色を指定しない。currentColor に追随するのでダークでも見える。塗りが要る部分だけ class="fill"、色を変えたい部分は class="accent1" か class="accent2" を付ける。アスキーアート、絵文字、矢印文字を図記号に使わない。

複数の系列を色で区別するときは c1 から順に付ける。5 色は色覚多様性に配慮した Okabe-Ito 系で、ダークでは明るい変種に切り替わる。本文の文字には使わない。

横に大きいものは .dg-wide を付けると、本文を離れて画面幅いっぱい (上限 1600px) に広がる。1 枚の横長画像なら figure.dg-wide、複数の図や画像を並べるなら .dg-grid.dg-wide の中に figure を置く。画像は img をそのまま入れる。

フローチャート、シーケンス図、状態遷移図は Mermaid で書く。pre.dg-mermaid に原文を置くと描画され、hover で出る copy ボタンから原文を取り出せる。一方向の単純な手順は図にせず ol.dg-steps にする。

数式

インラインは $...$、ディスプレイは $$...$$ で書く。ベクトルと行列は \boldsymbol にし、スカラーは装飾しない。幅広部品の上限 $W_{\mathrm{wide}}$ のようなインライン数式も本文の行送りを乱さない。

$$W_{\mathrm{wide}} = \min\left(W_{\mathrm{viewport}} - 64\,\mathrm{px},\ 1600\,\mathrm{px}\right)$$

どちらも hover で copy ボタンが出て、デリミタ込みの LaTeX を取り出せる。
