レイアウト

骨格は .dg-page の中に、ヘッダー、h1、リード文、目次、.dg-wrap、フッターを並べる。.dg-wrap の中は main と、任意の aside (用語集) の 2 つだけ。用語集は dl に dt と dd を並べる。aside があれば 2 カラム、なければ本文の行長を抑えた 1 カラムになる。切り替えのためのクラスは無い。

ヘッダーは span 2 つ。左に分類やテーマ、右に日付・版・実験番号など、その文書を特定する印を置く。

ダークモードの切り替えボタンはマークアップに書かない。theme.js が body に button.dg-theme-toggle を追加し、ウィンドウの右上に固定表示する。選択は localStorage に保存され、次回から描画前に反映される。

見出しは h2 を節に、h3 を小節に使う。目次の項目は h2 の id に対応させる。

小節の見出し

見出しに乗せると右に # が現れ、その見出しへのリンクになる。id を書かなかった見出しには文面から id が付く。

色のトークン

色はすべて CSS 変数で、ダークモードでは値だけが切り替わる。ページ固有の <style> や図の中で色を指定するときは、カラーコードを書かずにこの変数を参照する。ここに挙げていない変数 (本文や枠線の色など) は CSS が自動で当てるので、書き手が触ることはない。

本文

段落には リンク、strong (黒の太字)、em (アクセント色)、インラインコード を使える。CSS のような略語は abbr に title を付ける。アクセント色の強調は、節ごとに 1 箇所を目安にする。

並列の固有名や分類名は chip で並べる: Chrome Safari Firefox

系列を区別したい chip には c1〜c5 を順に付ける (図の色分けと同じパレット): 設計 実装 検証 納品 保守

  • 箇条書きは素の ul と ol を使う
    • 入れ子もそのまま書ける
  • 順番に意味のある手順は次の ol.dg-steps にする
  1. 原稿を {yyyymmdd}-{slug}.html として書き、隣に design-system/ を置く。
  2. screenshot.sh でライトとダークを描画し、画像を目で確認する。
  3. bundle.py で 1 ファイルにまとめて納品する。

ブロック

ブロックは 2 種類。読み飛ばしてほしくない内容は .dg-note に入れる。白地に枠で本文から浮き、data-label を書くと枠にまたがるタグが付く。ラベルの語で種別を示すので、色は変えない。

.dg-note は要約、注意、制限、前提などに使う。

data-label は省ける。種別を名乗るまでもないときはタグなしで書く。

本題から外れる前提や参考情報は .dg-sub に入れる。沈んだ面に乗り、枠を持たないので本文の流れを切らない。目次も同じ見た目になる。

補助情報のブロック。読まなくても本文が成立する内容を置く。

独立した情報のまとまりは .dg-card に入れる。複数を並べるときは .dg-grid で包むと、幅に応じて段数が自動で変わる。

Count-Min Sketch

幅と深さで誤差を制御する。過大評価だけが起こる。

Bloom Filter

集合への所属を判定する。偽陽性だけが起こる。

HyperLogLog

異なり数を推定する。誤差は相対的に一定。

引用は素の blockquote に p を入れる。訳文は p.dg-translation、出所は cite で書き、ウェブ上にあれば cite の中をリンクにする。訳文を小さくしたり薄くしたりしない。

コード

コードは pre > code.language-* に書く。Highlight.js が言語クラスを見て色を付ける。色付けしない場合は language-plaintext にする。

def estimate(sketch: list[list[int]], key: str) -> int:
    """d 個のセルの最小値を返す。真の頻度を下回らない。"""
    return min(row[h(key) % len(row)] for row, h in zip(sketch, HASHES))

差分は pre.dg-diff に書き、各行を span.add、span.del、span.ctx で包む。行頭の記号は CSS が付けるので書かない。緑と赤はこの部品だけの機能色。

aside table {
  white-space: nowrap;
  table-layout: fixed;
}

図

図は figure の直下に SVG、画像、または Mermaid を置き、figcaption で番号と説明を書く。自作図はインライン SVG で、線と文字は色を指定しない。currentColor に追随するのでダークでも見える。塗りが要る部分だけ class="fill"、色を変えたい部分は class="link" か class="accent" を付ける。

複数の系列を色で区別するときは c1 から順に付ける。5 色は色覚多様性に配慮した Okabe-Ito 系で、ダークでは明るい変種に切り替わる。本文の文字には使わない。

横に大きいものは .dg-wide を付けると、本文を離れて画面幅いっぱい (上限 1600px) に広がる。1 枚の横長画像なら figure.dg-wide、複数の図や画像を並べるなら .dg-grid.dg-wide の中に figure を置く。画像は img をそのまま入れる。

フローチャート、シーケンス図、状態遷移図は Mermaid で書く。pre.dg-mermaid に原文を置くと描画され、hover で出る copy ボタンから原文を取り出せる。

数式

インラインは $...$、ディスプレイは $$...$$ で書く。ベクトルと行列は \boldsymbol にし、スカラーは装飾しない。インライン数式 $\hat{f}(x) = \min_i C[i][h_i(x)]$ は本文の行送りを乱さない。

$$\Pr\left[\hat{f}(x) \ge f(x) + \varepsilon N\right] \le \delta, \quad w = \left\lceil \frac{e}{\varepsilon} \right\rceil,\ d = \left\lceil \ln \frac{1}{\delta} \right\rceil$$

どちらも hover で copy ボタンが出て、デリミタ込みの LaTeX を取り出せる。
