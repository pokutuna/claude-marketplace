本文

節は h2、小節は h3 にし、目次の各リンクは対応する h2 の id を参照する。段落には リンク、strong (黒の太字)、em (アクセント色)、インラインコード を使える。CSS のような略語は abbr に title を付ける。em は節ごとに 1 箇所を目安にする。

並列の固有名やファイル名は chip で並べる: template.html document.css bundle.py

図の系列と対応させる chip にだけ c1〜c5 を順に付ける: 構造 文字 表 図 コード

  • 箇条書きは素の ul と ol を使う
    • 入れ子もそのまま書ける
  • 順番に意味のある手順は次の ol.dg-steps にする
  1. template.html と design-system/ を作業ディレクトリへコピーする。
  2. このページの部品を使って本文を組む。
  3. bundle.py で単一ファイルにまとめて渡す。

hr は、見出しを立てるほどではないが話の向きが変わる切れ目にだけ置く。

コード

コードは pre > code.language-* に書く。色付けしない場合は language-plaintext にする。

<div class="dg-note" data-label="制限">
  <p>バンドラは stdlib だけで動く。外部パッケージは使えない。</p>
</div>

差分は pre.dg-diff に書き、各行を span.add、span.del、span.ctx で包む。行頭の記号は書かない。code は nohighlight にする。

aside table {
  white-space: nowrap;
  table-layout: fixed;
}

色のトークン

ページ固有の <style> や図の中で色を指定するときは、カラーコードを書かずに次の変数を参照する。ここにない色 (本文や枠線など) は CSS が当てるので書き手は触らない。

表 3. 書き手が指定する色トークン
トークン見本用途

--dg-accent2アクセント 2 (amber)。em と同じ色。図の中で注意を引く要素に
--dg-muted補助の色。図の注記や補足の線に

図の中では、変数を直接書く代わりに class="accent1"、class="accent2"、class="muted"、class="c1" のようなクラスでも指定できる。

図

図は figure の直下に SVG、画像、または Mermaid を置き、figcaption で番号と説明を書く。自作図はインライン SVG で、線と文字は色を指定しない。塗りが要る部分だけ class="fill"、色を変えたい部分は class="accent1" か class="accent2" を付ける。アスキーアート、絵文字、矢印文字を図記号に使わない。

複数の系列を色で区別するときは c1 から順に付ける。

横に大きいものは .dg-wide を付けると画面幅いっぱい (上限 1600px) に広がる。1 枚の横長画像なら figure.dg-wide、複数を並べるなら .dg-grid.dg-wide の中に figure を置く。.dg-table-scroll、table、pre にも付けられる。画像は img をそのまま入れる。

フローチャート、シーケンス図、状態遷移図は pre.dg-mermaid に Mermaid の原文を書く。一方向の単純な手順は図にせず ol.dg-steps にする。ノードが 4 つ以上かラベルが長いときは縦方向 (flowchart TD) に組み、矢印の交差を避ける。ノード内に <br/> を書かず、改行が要るなら / で区切るか 1 行に収まるよう短くする。

数式

インラインは $...$、ディスプレイは $$...$$ で書く。ベクトルと行列は \boldsymbol にし、スカラーは装飾しない。幅広部品の上限 $W_{\mathrm{wide}}$ のようなインライン数式も本文の行送りを乱さない。

$$W_{\mathrm{wide}} = \min\left(W_{\mathrm{viewport}} - 64\,\mathrm{px},\ 1600\,\mathrm{px}\right)$$
